# Waifu Code ♡

Редактор на базе Code OSS/VSCodium с темой Waifu Midnight и собственной системой **Waifu Addons**. В этом репозитории находятся исходники редактора, менеджер аддонов 0.4.1, публичный каталог с API и сайт для публикации модулей.

## Состав проекта

| Папка | Содержимое |
| --- | --- |
| [waifu-code](waifu-code) | Исходный форк Code OSS, оформление, менеджер аддонов и сборочные скрипты |
| [waifu-code/extensions/waifu-addons](waifu-code/extensions/waifu-addons) | Worker runtime, API, интерфейс менеджера, примеры и тесты |
| [waifu-addons-server](waifu-addons-server) | Сервер каталога, сайт, файловое хранилище и Docker/nginx |
| [docs](docs) | Инструкция для нейросетей и справочник API |

## Сервер и сайт через Docker

На Linux-сервере с Docker Engine и Compose v2:

```bash
cd waifu-addons-server
docker compose up -d --build
```

Сайт: `http://localhost:4853`. Внешний порт 4853 принимает nginx, сервер работает в отдельной Docker-сети. Публикация требует ключ издателя, скачивание открыто всем. Данные сохраняются в Docker volume.

[Инструкция Docker, HTTPS и nginx на хосте](waifu-addons-server/README-DOCKER.md). Для прямого запуска без Docker нужен Node.js 22+:

```bash
cd waifu-addons-server
npm start
```

По умолчанию прямой Node-сервер слушает `127.0.0.1:4317`; Docker-конфигурация задаёт порт 4853. Ключ первого издателя создаётся локально при запуске. Ключей, токенов, сертификатов, базы каталога и пользовательских профилей в репозитории нет.

## Waifu Addons

Формат модуля: `waifu-addon.json` + точка входа `.cjs`, `apiVersion: 1`. Аддоны поддерживают команды, работу с выделением, webview-панели, выбранные изображения, файловые диалоги, отменяемые фоновые задачи, настройки, секреты и жизненный цикл.

- [Инструкция для нейросетей](docs/WAIFU-ADDONS-AI-GUIDE.md)
- [Расширенный API 0.4](docs/WAIFU-ADDONS-API-0.4.md)
- [Пример фотогалереи](waifu-code/extensions/waifu-addons/examples/photo-gallery)

Аддоны выполняют доверенный Node.js-код с правами пользователя; Worker не является защитной песочницей. Установка и выполнение требуют доверенного рабочего пространства. Пакеты проверяются по формату, путям и SHA-256.

В менеджере настроен каталог владельца `http://132.243.115.51:4853`. Изменить адрес можно через `waifuAddons.registryUrl` в пользовательских настройках редактора. Для остальных удалённых серверов нужен HTTPS; HTTP допускается для localhost и указанного адреса владельца.

## Проверки

Без установки зависимостей всего Code OSS, на Node.js 24:

```bash
node --test waifu-code/extensions/waifu-addons/test/*.test.cjs waifu-addons-server/test/*.test.mjs
```

Набор включает реальную публикацию/загрузку через тестовый HTTP-сервер, проверку SHA-256 и путей, разрешения API, Worker, отмену фоновых задач и очистку ресурсов. Тестовые каталоги и ключи создаются временно. GitHub Actions запускает эти проверки при push/PR.

Браузерные проверки требуют Playwright и установленного Chrome. Проверка настоящего редактора требует отдельно собранную/подготовленную Windows portable-версию. Эти проверки не входят в лёгкий CI.

## Сборка редактора

Исходники редактора основаны на dev-снимке Code OSS 1.144.0. Подготовленная ранее portable-версия использует бинарную базу VSCodium 1.140.06880 и не включена в Git. Полная сборка текущего dev-снимка ещё не подтверждена успешным результатом; подробности — [BUILD-STATUS](waifu-code/BUILD-STATUS.md).

Для сборки из исходников см. [инструкции редактора](waifu-code/README-WAIFU.md), `.nvmrc` и `Build-Waifu.cmd`. Подготовлен ручной workflow **Waifu Code Windows**; он не запускается автоматически при первой публикации. Скрипт `waifu-code/scripts/package-waifu-portable.cjs` позволяет применить оформление и встроенные аддоны к распакованному VSCodium.
