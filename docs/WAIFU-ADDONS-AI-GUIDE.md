# Инструкция для нейросетей: разработка Waifu Addons

Этот файл можно целиком прикрепить к запросу любой нейросети. Он описывает реализованный Waifu Addons API v1 в менеджере 0.4. Расширенные методы описаны в приложении [WAIFU-ADDONS-API-0.4.md](WAIFU-ADDONS-API-0.4.md); для модулей с панелями прикладывай оба файла. Сверено с исходниками 22 октября 2026 года.

## Роль и задача

Ты разрабатываешь модуль для Waifu Code — Waifu Addon. Выполни задачу пользователя, создай готовые файлы аддона и README с установкой и проверкой. Используй только API, описанный ниже. Если задача требует недоступного API редактора, прямо назови ограничение и предложи конкретное расширение самого менеджера. Не выдавай неподдерживаемую функцию за работающую.

Waifu Addons имеет собственный формат. Не создавай VSIX, manifest VS Code, activationEvents или contributes. Не импортируй `vscode`: объект API передаётся в `activate(api)`. Панель создавай через api.panels; её HTML/JS передаются менеджеру, отдельно от кода Worker.

## Структура модуля

```text
my-addon/
  waifu-addon.json
  main.cjs
  README.md
```

Манифест находится в корне. Точка входа — CommonJS `.cjs`. Дополнительные файлы допустимы; относительные импорты через `require('./helper.cjs')` должны указывать на существующие файлы внутри пакета. Для простых модулей достаточно одного main.cjs. Зависимости npm при необходимости заранее объедини в готовый файл; менеджер не запускает npm install.

## Манифест

```json
{
  "id": "my-addon",
  "name": "My Waifu Addon",
  "description": "Кратко опиши реальное действие модуля.",
  "version": "1.0.0",
  "apiVersion": 1,
  "main": "main.cjs",
  "permissions": ["editor.read", "editor.write"],
  "commands": [
    {"id": "waifu.my-addon.transform", "title": "Преобразовать выделенный текст"}
  ]
}
```

- `id`: от 2 до 64 символов; первая буква a–z, далее только a–z, цифры и дефис. Стабильный уникальный идентификатор; не меняй при обновлениях.
- `name`: непустая строка до 100 символов.
- `description`: необязательная строка до 1000 символов.
- `version`: три целых неотрицательных числа `major.minor.patch`, без ведущих нулей и суффиксов. Каждая часть до 9 цифр. Например `1.0.1`; `1.0.1-beta` не поддерживается.
- `apiVersion`: строго число `1`.
- `main`: относительный путь к существующему `.cjs`, например `main.cjs`.
- `permissions`: editor.read, editor.write, ui.panels, files.read, files.write, tasks.background, storage.settings, storage.secrets. Запрашивай только нужные. Если API с разрешениями не нужен, укажи `[]`.
- `commands`: до 50 команд с уникальными ID. Каждый ID начинается с `waifu.<id-модуля>.`, содержит только латинские буквы, цифры, точки и дефисы, общая длина до 150 символов. `title` — непустая строка до 100 символов.

Поле `publisher` при публикации задаёт сервер по ключу издателя. Не подделывай издателя и не добавляй ключ в манифест. Не рассчитывай на дополнительные поля манифеста: сервер нормализует его и удаляет неизвестные поля.

## Базовый API v1

| Вызов | Результат и поведение | Разрешение |
| --- | --- | --- |
| `api.commands.register(id, handler)` | Регистрирует функцию без аргументов; обработчик может быть async. Возвращаемое значение не используется. | Нет |
| `api.window.showInformationMessage(text)` | Показывает уведомление; максимум 2000 символов. Не возвращает выбранную кнопку или Promise результата диалога. | Нет |
| `api.log(text)` | Пишет в канал вывода менеджера; максимум 10000 символов за сообщение. | Нет |
| `await api.editor.getSelectedText()` | `Promise<string>`: текст текущего выделения; пустая строка при пустом выделении. | `editor.read` |
| `await api.editor.replaceSelection(text)` | `Promise<boolean>`: результат применения правки. Заменяет текущее выделение; при пустом выделении вставляет текст в позицию курсора. | `editor.write` |

Для операций с текстом должен быть открыт редактор; используется активный либо последний запомненный текстовый редактор. Эти методы работают с одним текущим выделением. Между чтением и записью пользователь может переключить файл или выделение, поэтому избегай долгих ожиданий перед записью. Транзакционного API с привязкой к документу и версии сейчас нет.

`replaceSelection` принимает строку длиной до 1 000 000 символов. Проверяй возвращаемый boolean; `false` означает, что правка не применена. Обычная отмена правки доступна через Ctrl+Z.

Обязательно зарегистрируй в activate каждую объявленную команду с тем же ID. Не регистрируй команды других модулей. `register` не возвращает disposable.

В менеджере 0.4 доступны панели, чтение выбранных файлов/папок, сохранение по выбранному пути, настройки, секреты, фоновые задачи и жизненный цикл. Точные сигнатуры и ограничения см. в приложении WAIFU-ADDONS-API-0.4.md. Произвольное открытие документов, получение пути проекта/полного текста документа, терминал, status bar, события редактора, автодополнение, подсветка и языковой сервер по-прежнему не доступны через API менеджера. Не придумывай методы.

## Точка входа и выполнение

Экспортируй `exports.activate = api => { ... }` или async-функцию с тем же экспортом. Менеджер загружает её в Node.js Worker и ожидает активацию перед выполнением команды. В Worker нет DOM или window браузера. Код панели выполняется отдельно в webview, там доступны DOM и acquireVsCodeApi(); React при необходимости нужно заранее собрать без внешних CDN. Не храни токены в панели.

Код работает с правами пользователя. Worker не является защитной песочницей: разрешения манифеста регулируют только API редактора. Node.js может обращаться к файлам и сети. Не добавляй скрытые сетевые запросы, сбор данных, запуск shell-команд или чтение посторонних файлов. Если такие операции нужны по задаче, объясни их в README и сделай явно вызываемыми пользователем. Не включай секреты в код, README, логи или пакет.

Установка и выполнение требуют доверенного рабочего пространства. Ошибки обработчика передаются менеджеру. Обычная команда ограничена 10 секундами вместе с ожиданием активации; при превышении Worker останавливается. Долгие операции запускай через api.tasks.start: их callback не ограничен 10 секундами и получает AbortSignal. Обычный RPC — 5 секунд, файловый диалог — 120 секунд; при ожидании диалога таймер команды продлевается. Есть api.lifecycle.onDispose(handler) и необязательный exports.deactivate; на завершение Worker отводится до 1,5 секунды. Точные правила см. в приложении.

## Рабочий пример main.cjs

Для манифеста выше:

```js
'use strict';

exports.activate = api => {
  api.commands.register('waifu.my-addon.transform', async () => {
    const selected = await api.editor.getSelectedText();
    if (selected.length === 0) {
      api.window.showInformationMessage('Сначала выдели текст.');
      return;
    }

    const result = selected.toUpperCase();
    if (result.length > 1_000_000) {
      throw new Error('Результат превышает допустимый размер.');
    }
    const applied = await api.editor.replaceSelection(result);
    if (!applied) {
      throw new Error('Редактор не смог применить изменение.');
    }
    api.log('Преобразование выполнено.');
  });
};
```

Не записывай исходный текст пользователя в лог. Для повторных запусков не сохраняй выделение в глобальной переменной: читай его внутри обработчика.

## Установка, упаковка и публикация

Для локальной проверки открой Waifu Addons в Waifu Code, выбери Install from Folder и папку, внутри которой непосредственно находится waifu-addon.json. Затем открой текстовый файл, выдели текст и запусти команду через страницу аддона или палитру команд.

Каталог: https://waifu-addons-hub-7f21.majorbuddy12.chatgpt.site/

Через форму публикации можно выбрать папку модуля или готовый `.waifu`. Публикация требует ключ издателя; скачивание публичное. Пользователь вводит ключ самостоятельно. Не проси прислать ключ нейросети.

Для упаковки через Node.js 22+ из папки `waifu-addons-server`:

```powershell
node cli.mjs pack "C:\path\my-addon" "C:\path\my-addon.waifu"
```

`.waifu` — JSON-контейнер, не ZIP и не переименованный VSIX. Лучше использовать штатную упаковку или сайт. Его формат: `{"format":"waifu-addon-v1","files":[{"path":"main.cjs","data":"<base64 содержимого файла>"}, ...]}`; манифест также входит в files. Ручное создание base64 нейросетью не требуется.

Ограничения публикации:

- До 200 файлов, до 2 МиБ на файл, суммарно до 8 МиБ распакованных данных; тело пакета до 12 МиБ.
- Пути относительные, с `/`, до 240 символов. Без `..`, абсолютных путей, обратных слешей, символических ссылок, скрытых компонентов, node_modules и .git.
- Не используй имена устройств Windows, завершающие точку/пробел, дубли путей с разным регистром и конфликты «файл/папка».
- Никогда не включай `.env`, ключи, токены, пользовательские данные и каталоги разработки. Готовый `.waifu` сохраняй вне упаковываемой папки.
- Обновление публикуется с тем же id и большей версией, ключом того же издателя. Опубликованную версию перезаписать нельзя. Менеджер 0.4 требует удалить установленный аддон перед установкой новой версии; автоматическое обновление не реализовано.

## Проверка перед выдачей результата

1. JSON разбирается, main существует, exports.activate — функция, все команды совпадают с манифестом.
2. Запрошены только нужные разрешения; нет обращения к выдуманному API.
3. Установка из папки и упаковка штатным CLI проходят без ошибок.
4. Команда работает на обычном тексте, кириллице, Unicode и многострочном выделении; пустое выделение обработано осмысленно.
5. Для преобразований Ctrl+Z возвращает исходный текст; ошибки и отказ применения правки обрабатываются.
6. Повторный запуск, отключение и включение аддона работают; нет бесконечных задач и секретов в пакете.

Не утверждай, что проверка выполнена, если ты её не запускал. Отдельно перечисли проведённые проверки и то, что пользователь должен проверить в редакторе.

## Требуемый ответ нейросети

Выдай дерево файлов и полное содержимое каждого файла без заглушек, инструкцию установки и короткий сценарий проверки. Если доступна файловая система, создай готовую папку и по возможности `.waifu`. Не ограничивайся описанием идеи. README должен объяснять действие команд, разрешения, ограничения и внешние обращения, если они есть.
