# Темы Waifu Code

Нажмите `Ctrl+K`, затем `Ctrl+T` и выберите тему:

| Тема | Оформление |
| --- | --- |
| Waifu Midnight | Тёмное розово-лиловое |
| Waifu Sakura | Светлое розовое |
| Waifu Moonlight | Тёмное сине-лунное |
| Waifu Cyber Neko | Тёмное с неоновыми акцентами |
| Waifu Matcha | Светлое зелёно-кремовое |
| Waifu Sunset | Тёплое персиковое на тёмном фоне |

У каждой темы свой оригинальный фон, созданный с помощью imagegen для этой сборки. Шесть изображений находятся в `waifu-code/extensions/waifu-addons/media/backgrounds/` и работают без сети. Поверх изображения лежит заливка цвета темы для читаемости текста. Фон распространяется на окно редактора, настройки, боковые панели, терминал и встроенные страницы Waifu. Webview со стандартными цветами редактора используют прозрачные поверхности; аддоны с собственной сплошной заливкой могут сохранять своё оформление. Для оформления без картинки можно выбрать любую стандартную тему редактора.

Темы Waifu находятся в начале списка Color Themes. По умолчанию используется Waifu Midnight; сохранённый выбор пользователя имеет приоритет.

Цветовые темы работают как стандартные темы VS Code. Фон — часть собственной сборки Waifu Code: `scripts/apply-waifu-backgrounds.cjs` добавляет локальный CSS при упаковке portable-дистрибутива. Для сборки из исходников примените этот сценарий к папке `resources/app` после упаковки. Контрольная сумма изменённого CSS обновляется в метаданных продукта, если она присутствует. Повторный запуск заменяет предыдущий блок CSS.
