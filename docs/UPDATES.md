# Обновления Waifu Code

Автообновление работает в Windows User Setup, начиная с 0.4.2. С версии 0.4.1 нужно один раз установить новый пакет вручную. Для portable команда проверки открывает страницу релизов, не заменяя папку portable-дистрибутива.

Через 30 секунд после запуска и каждые 6 часов менеджер проверяет последний стабильный релиз `mabogma/waifu-code`. Новый установщик скачивается в пользовательское хранилище Waifu Addons с прогрессом и отменой. Проверяются имя файла, принадлежность репозиторию, HTTPS, размер и SHA-256 из метаданных GitHub. Предварительные версии и откат на старую версию исключены. Токен GitHub не нужен.

После скачивания появится **Restart and Update**. Редактор сохраняет документы; если сохранение отменено и остаются изменённые документы, обновление не запускается. Установщик ждёт закрытия процессов Waifu Code, выполняет обновление для текущего пользователя и запускает редактор. Если закрытие отменено, ожидание завершается через две минуты. Настройки и аддоны остаются вне папки установки.

Ручная проверка: `Ctrl+Shift+P` → `Waifu Code: Check for Updates`. Фоновую проверку и скачивание можно отключить через `waifuUpdates.enabled`. Ошибки доступны в Output → Waifu Updates; при ручной проверке также выводится уведомление.

Файлы пока не подписаны сертификатом издателя. Проверка SHA-256 подтверждает соответствие опубликованному файлу, но не заменяет цифровую подпись. Защита релизов зависит от доступа к GitHub-репозиторию.
