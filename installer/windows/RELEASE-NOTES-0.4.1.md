# Waifu Code 0.4.1 — Windows User Setup

Первый установщик Waifu Code для Windows x64 с русским и английским мастером. Скачай **WaifuCodeUserSetup-x64-0.4.1.exe**, запусти и выбери папку установки.

- Установка для текущего пользователя без прав администратора.
- Меню «Пуск», опциональный ярлык рабочего стола, команда `waifu-code` в PATH.
- Опциональные пункты «Открыть в Waifu Code» для файлов и папок.
- Удаление через настройки Windows с сохранением пользовательского профиля.
- Waifu Midnight и Waifu Addons 0.4.1 с панелями, изображениями, отменяемыми задачами, настройками и секретами.
- Ещё пять тем: Sakura, Moonlight, Cyber Neko, Matcha и Sunset. У каждой из шести тем свой оригинальный аниме-фон; картинки загружаются локально, без интернета.
- Темы Waifu стоят в начале списка Color Themes. Тема по умолчанию — Waifu Midnight.
- Собственный логотип Waifu Code в EXE, окнах, пустом редакторе и плитках Windows.
- Выбор оформления: `Ctrl+K`, затем `Ctrl+T` → тема `Waifu …`.
- Каталог аддонов: http://132.243.115.51:4853.

Основа: официальный VSCodium Windows x64 **1.140.06880**; это отдельная сборка с оформлением Waifu Code и встроенным менеджером. Бинарник не является результатом полной компиляции dev-снимка Code OSS 1.144.0 из репозитория.

Установщик не содержит личного профиля, токенов издателя и пользовательских расширений. Сохраняются оригинальные лицензии компонентов. Автоматическое обновление редактора пока не включено; новые версии устанавливаются вручную.

**Пакет не подписан цифровым сертификатом издателя**, поэтому Windows может показать проверку неизвестного приложения. Файл **SHA256SUMS.txt** содержит контрольную сумму установщика.
