# Waifu Code 0.4.3

Исправлено отображение обоев вне Waifu Addons. Общий фон перекрывали подложка сетки, внутренний контейнер редактора и заливки панелей с более высоким приоритетом CSS. Теперь эти поверхности прозрачны для тем Waifu; стандартные темы, рамки панелей, выделения и заливка всплывающих окон сохраняются.

Исправление проверено в установленном редакторе и сравнением пикселей отдельно под кодом и проводником: все шесть тем, обычный и плавающий компактный режим — 12 комбинаций. В 0.4.2 проблема воспроизводилась даже при успешно загруженной картинке.

Обновление доступно через `Waifu Code: Check for Updates` в версии 0.4.2. После применения обновления редактор перезапустится. Также можно скачать и установить **WaifuCodeUserSetup-x64-0.4.3.exe** вручную. Настройки и аддоны сохраняются.

Основа — официальный VSCodium Windows x64 1.140.06880 с собственным оформлением Waifu Code. Установщик пока без цифровой подписи; контрольная сумма опубликована в `SHA256SUMS.txt`.
