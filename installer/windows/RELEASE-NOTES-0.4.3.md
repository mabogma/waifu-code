# Waifu Code 0.4.3

Исправлено отображение обоев вне Waifu Addons. В режиме плавающих панелей непрозрачная подложка сетки перекрывала общий фон окна. Теперь эта подложка прозрачна для тем Waifu; стандартные темы и заливка всплывающих окон сохраняются.

Исправление проверено сравнением пикселей в изолированном тесте: все шесть тем, обычный и плавающий режим — 12 комбинаций. В 0.4.2 проблема воспроизводилась даже при успешно загруженной картинке.

Обновление доступно через `Waifu Code: Check for Updates` в версии 0.4.2. После применения обновления редактор перезапустится. Также можно скачать и установить **WaifuCodeUserSetup-x64-0.4.3.exe** вручную. Настройки и аддоны сохраняются.

Основа — официальный VSCodium Windows x64 1.140.06880 с собственным оформлением Waifu Code. Установщик пока без цифровой подписи; контрольная сумма опубликована в `SHA256SUMS.txt`.
