# Waifu Code 0.4.2

- Фон выбранной темы теперь распространяется на всё окно: редактор, пустую область, боковые панели, настройки и терминал.
- Стартовая страница и каталог Waifu Addons используют фон текущей темы и меняются вместе с ней.
- Webview, использующие стандартные цвета редактора, показывают общий фон. Аддоны со своей сплошной заливкой могут сохранять собственное оформление.
- Автообновление установленной Windows-версии из стабильных GitHub Releases: проверка при запуске и каждые 6 часов, фоновое скачивание и сверка SHA-256. Установка запускается после кнопки **Restart and Update**, сохранения документов и закрытия редактора.
- Ручная проверка: `Ctrl+Shift+P` → `Waifu Code: Check for Updates`. Отключение фоновой проверки: `waifuUpdates.enabled: false`.

С версии 0.4.1 требуется один раз установить этот пакет вручную. Дальнейшие обновления будут предлагаться автоматически. Для portable-версии команда открывает страницу релизов.

Основа — официальный VSCodium Windows x64 1.140.06880 с собственным оформлением и встроенными компонентами Waifu Code. Это не результат полной компиляции отдельного dev-снимка Code OSS. Исходные лицензии сохранены. Установщик не подписан цифровым сертификатом; SHA-256 находится в `SHA256SUMS.txt`.
