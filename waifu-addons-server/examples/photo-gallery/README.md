# Waifu Photo Gallery

Нужен Waifu Addons 0.4 или новее. Установи из папки либо пакета, затем запусти «Открыть фотогалерею». Выбери фотографии, фильтруй их по имени, нажми на миниатюру для просмотра и «Сохранить копию…» для сохранения через диалог.

PNG, JPEG, WebP, GIF, BMP; файл до 20 МиБ. До 200 изображений и 64 МиБ исходных изображений на панель. Для новой подборки закрой панель и открой заново. Размер миниатюр сохраняется между запусками. В панели создаются уменьшенные WebP-миниатюры до 360px; просмотр открывает оригинал. Если преобразование canvas недоступно, остаётся локальный оригинал. Анимированные изображения получают статическую миниатюру.

Разрешения: ui.panels — панель, files.read — выбранные изображения, files.write — выбранный путь сохранения, tasks.background — прогресс/отмена предзагрузки, storage.settings — размер миниатюр. Нет сети, загрузок на сервер, токенов и внешних зависимостей. Системные диалоги не закрываются программно при отмене; после закрытия результат отменённой задачи отбрасывается.

Проверка: выбери две фотографии, проверь фильтр, просмотр и сохранение копии. Измени размер миниатюр и открой панель заново. Отмени предзагрузку, затем отключи аддон: панели должны закрыться. Исходные изображения не изменяются.
