# Waifu Code — итог проверки

## Готовое приложение

`../WaifuCode-Windows-x64/Waifu Code.exe` — отдельный запускаемый portable-редактор. Для запуска не нужны Node.js, Visual Studio или сборка исходников. Вся папка приложения должна оставаться целой.

Основа: официальный VSCodium 1.140.06880 (Code OSS 1.140.0). Архив проверен по SHA-256 из GitHub Releases: `024ae1e88f431aee300e73c2ece92e42ebde80a7f3c484ff684f455ffa6a6a7f`. Название продукта, Windows-идентификаторы, исполняемый файл, значок и метаданные изменены на Waifu Code. Исходные лицензии сохранены. Происхождение записано в `WAIFU-BUILD.json` внутри приложения.

Встроены тема Waifu Midnight, стартовая страница с SVG-маскотом, менеджер Waifu Addons и два примера аддонов. Настройки и дополнения находятся в папке `data` приложения. Обычный каталог расширений Open VSX, предусмотренный VSCodium, сохранён; собственные Waifu Addons устанавливаются из папок.

## Исходники

Папка `waifu-code` содержит отдельно изменённый снимок исходников microsoft/vscode main, версия 1.144.0 dev. Это более новый снимок, чем основа portable-приложения. Portable-версия собрана из готового официального бинарного дистрибутива VSCodium с собственными изменениями продукта и расширениями; она не является результатом локальной компиляции этого dev-снимка.

С разрешения пользователя установлены MSVC Spectre-библиотеки и ATL Spectre. Проверка инструментов сборки прошла. Полная установка зависимостей и компиляция dev-снимка не завершены; оставшиеся запущенные задачи остановлены. Скрипты `Build-Waifu.cmd`, `Start-Waifu.cmd`, `scripts/waifu-doctor.cjs` сохранены для продолжения сборки из исходников.

`scripts/package-waifu-portable.cjs` воспроизводит изменения portable-дистрибутива из распакованной официальной сборки. Замена Windows-значка и метаданных exe выполнялась дополнительно инструментом `node_modules/rcedit/bin/rcedit.exe`.

## Ограничения первой версии

Собственный сетевой каталог, подписи пакетов и автоматическое обновление Waifu Addons пока не реализованы. Аддоны исполняют доверенный Node.js-код с правами пользователя; рабочий поток не является защитной песочницей. Разрешения editor.read и editor.write относятся к API менеджера.

## Обновление Waifu Addons 0.2

Добавлен интерфейс в стиле обычных расширений VS Code: поиск, Installed / Available, строки с описанием, издателем и версией, отдельная страница подробностей и кнопки установки и управления. Используются цвета текущей темы и безопасный вывод пользовательского текста. Веб-представления имеют CSP и проверяют действия на стороне extension host.

Все 10 тестов аддонов и менеджера прошли. Браузерная проверка через установленный Chrome прошла: поиск, сохранение фокуса, переход в подробности, установка, запуск команды, узкая панель, безопасный вывод текста. Превью панели и страницы сохранены рядом с portable-папкой в waifu-addons-sidebar.png и waifu-addons-details.png; это изображения фронтенда в браузерном движке, не снимки всего окна IDE.

Интеграционный тест обновлённой portable-сборки прошёл со встроенным менеджером 0.2.0: открытие панели и страницы аддона, редактирование со страницы, Ctrl+Z, отключение, включение и установка. Обновление внесено в исходники и resources/app/extensions/waifu-addons готового приложения. Пользовательские настройки и установленные аддоны не заменялись.
